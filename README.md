# My Ledger

A premium personal finance desktop application built to help users track daily expenses, monitor spending habits, manage budgets, and stay motivated to save money.

## ✨ Features

- 🔐 Secure local login
- 💰 Daily expense tracking
- 📊 Spending analytics
- 🎯 Budget management
- 📅 Expense history
- 🌙 Modern dark UI
- 💻 Native macOS desktop application (Tauri)

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Tauri
- Rust

## 🚀 Getting Started

```bash
npm install
npm run tauri dev
```

## 📦 Build

```bash
npm run tauri build
```
